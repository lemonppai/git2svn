# git2svn

交互式命令行工具，将 **Git** 仓库指定分支的代码一键同步到 **SVN** 仓库。

适用于「开发在 Git、发布/归档在 SVN」的团队场景：工具会拉取 Git 代码、清理 SVN 工作副本、同步差异（新增/修改/删除），最后提交到 SVN。

## 功能特性

- 📋 **项目清单**：自动解析项目 `README.md` 中的配置表格，菜单选择项目，无需重复输入仓库地址
- 🚀 **一键同步**：`git clone`（浅克隆）→ `svn checkout` → 清理 → 覆盖 → 提交，全流程自动完成
- 🔍 **差异处理**：自动执行 `svn add` / `svn delete`，正确处理新增、修改、删除三类变更
- 📊 **变更统计**：提交前展示新增（A）、修改（M）、删除（D）文件数量
- 🔁 **自动重试**：`svn commit` 失败自动重试最多 5 次
- 💬 **交互确认**：同步前二次确认，提交信息手动输入，防止误操作

## 环境要求

| 依赖 | 版本要求 |
| ---- | -------- |
| Node.js | >= 23.0.0 |
| git | 已安装并可用 |
| svn | 已安装并可用（需有目标仓库的读写权限） |

## 安装

```bash
# 全局安装（推荐，获得 git2svn 命令）
npm install -g git2svn

# 或本地安装
npm install git2svn
```

## 使用

```bash
git2svn
```

### 同步流程

1. **选择项目**：读取当前目录 `README.md` 中的配置表格，列出可选项目；选择「其他项目」则手动输入
2. **手动输入**（无配置表格时）：依次输入 Git 仓库地址、Git 分支名、SVN 仓库地址，带格式校验
3. **二次确认**：展示仓库信息，确认后开始同步
4. **执行同步**：拉取 Git / SVN 仓库 → 清理并覆盖 → 处理变更 → 展示变更统计
5. **提交**：输入 SVN 提交信息，执行 `svn commit`

### 项目配置表格

在项目 `README.md` 中添加如下格式的表格（表头必须一致），即可使用菜单快速选择：

```markdown
| 项目名 | Git仓库地址 | Git分支 | Svn仓库地址 |
| ------ | ----------- | ------- | ----------- |
| demo   | https://github.com/user/demo.git | master | svn://svn.example.com/trunk/demo |
```

### 手动输入格式要求

- **Git 仓库**：`https://host/user/repo.git`（支持端口号，`.git` 后缀可省略）
- **Git 分支**：字母、数字、下划线、中划线（如 `master`、`develop-v2`）
- **SVN 仓库**：`svn://host/path` 或 `svn+ssh://user@host/path`

## 工作目录说明

同步过程会在**当前目录**下生成工作副本：

```
dist/
├── git/<md5>   # Git 浅克隆工作副本（按 仓库地址#分支 生成哈希）
└── svn/<md5>   # SVN 工作副本（按 仓库地址 生成哈希）
```

每次同步都会重新克隆 Git 仓库、重建 SVN 工作副本，可随时手动删除 `dist` 目录，不影响下次使用。

> ⚠️ 注意：SVN 工作副本会被清空后整体覆盖，SVN 仓库中与本次同步无关的历史文件将被删除，请确认 SVN 目标路径专用于存放该 Git 分支的产物。
